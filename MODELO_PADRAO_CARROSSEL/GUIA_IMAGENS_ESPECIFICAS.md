# 🎨 GUIA: IMAGENS ESPECÍFICAS POR TEMA

## 🎯 PROBLEMA IDENTIFICADO
**Antes:** Imagens genéricas (dinheiro, tecnologia, etc.)
**Agora:** Imagens ESPECÍFICAS das empresas/pessoas citadas

## 📋 CHECKLIST PARA IMAGENS TEMÁTICAS

### ✅ SLIDE 1: Logo/Interface da empresa principal
**Exemplo TikTok:**

- Interface do app
- Tela de smartphone com TikTok aberto

### ✅ SLIDE 2: Instituição reguladora
**Exemplo Banco Central:**

### ✅ SLIDE 3: Conceito específico da licença
**Exemplo Licenças:**
- Documentos oficiais

### ✅ SLIDE 4: Dados/mercado específico
**Exemplo Usuários:**
- Gráficos com números reais

### ✅ SLIDE 5: Comparação com casos similares

### ✅ SLIDE 7: Privacidade/dados

### ✅ SLIDE 8: Timeline/próximos passos
**Exemplo Cronograma:**
- Calendário com datas

### ✅ SLIDE 9: CTA/compartilhamento
**Exemplo Social:**
- Ícones de redes sociais

## 🔍 COMO BUSCAR IMAGENS ESPECÍFICAS

### 📱 **Para Empresas de Tech:**
```
Termos: "[empresa] logo", "[empresa] app interface", "[empresa] headquarters"
Exemplo: "tiktok logo", "tiktok app interface", "bytedance headquarters"
```

### 🏛️ **Para Instituições:**
```
Termos: "[instituição] building", "[instituição] logo", "[pessoa] [cargo]"
Exemplo: "banco central brasil building", "gabriel galipolo banco central"
```

### 📊 **Para Dados/Estatísticas:**
```
Termos: "brazil statistics", "[tema] data visualization", "[tema] infographic"
Exemplo: "brazil mobile users", "fintech data visualization"
```

### 🌏 **Para Comparações Internacionais:**
```
Termos: "[exemplo] interface", "[país] [serviço]", "[empresa competidora]"
Exemplo: "wechat pay interface", "china mobile payments", "alipay app"
```

- Dinheiro genérico

### ✅ USE:

- Pessoas específicas mencionadas
- Interfaces reais dos apps
- Prédios/locais específicos
