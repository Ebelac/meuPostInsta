# Custom images por slide

Coloque imagens aqui com nome `1.png` ... `9.png` (número do arquivo = número do slide). Quando você roda `/carousel` com `fonte_imagens=pasta`, o gerador usa essas imagens em vez de buscar em Unsplash.

Aceita `.jpg`, `.jpeg`, `.png`. As imagens são redimensionadas pra preencher a área visual de cada slide (1080px de largura).

Esta pasta está no `.gitignore` — suas imagens não vão pro repo.
