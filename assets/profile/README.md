# Profile Assets

## Como usar:

### 1. Foto de Perfil
Coloque sua foto de perfil nesta pasta com o nome:
- `profile_photo.jpg` ou `profile_photo.png`
- Recomendado: 200x200px ou maior (será redimensionada automaticamente)
- Formato quadrado para melhor resultado

### 2. Símbolo de Verificado (opcional)
Se você quiser um símbolo personalizado, coloque aqui:
- `verified_badge.png` (com fundo transparente)
- Tamanho recomendado: 32x32px

## Estrutura atual:
```
assets/profile/
├── README.md (este arquivo)
├── profile_photo.jpg (SUA FOTO AQUI)
└── verified_badge.png (OPCIONAL - símbolo personalizado)
```
